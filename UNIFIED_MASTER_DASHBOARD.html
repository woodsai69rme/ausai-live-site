Australian Carrier Unlock Guide

Before you start: Australian carriers must unlock your phone for free if:
  • The phone is paid off (no outstanding contract)
  • Not reported as lost or stolen
  • IMEI is clean (not blacklisted)

Step 1: Identify Your Carrier Lock

Run this ADB command (Samsung)
adb shell getprop ro.csc.sales_code

Common results:

XSA / XSP → Unlocked ✓
TEL → Telstra
VAU / VA → Vodafone
OPP / OPS → Optus
INU → Singtel

Telstra Unlock (Code: TEL)

1
Check eligibility

Phone must be out of contract / paid off. You can do this even if you're not a Telstra customer.

2
Submit unlock request

Call 125 111 (Telstra support) or visit telstra.com.au/devices/unlock

3
Provide IMEI
adb shell getprop gsm.baseband.imei

Or dial *#06# on the phone.

4
Wait for unlock code

Telstra typically sends the unlock code via SMS within 1-2 business days. Some prepaid phones qualify after 6 months of active use.

5
Enter unlock code

Insert a non-Telstra SIM → turn on → enter the code when prompted. If no prompt appears, go to Settings → Connections → SIM Card Manager → SIM Lock.

Note for Belong users: Belong is a Telstra MVNO. If your phone is TEL-locked, Belong should work since Belong uses Telstra's network. If it doesn't, contact Belong support.

Optus Unlock (Code: OPP/OPS)

1
Check eligibility

Postpaid: phone must be paid off. Prepaid: requires 6 months continuous active service on an Optus prepaid plan with a recharge in the last 30 days.

2
Submit unlock request

Visit: optus.com.au/prepaid/unlock-your-phone
Or call 133 937 (Optus support)

3
Use Optus Unlock App (Samsung)

If available, download "Optus Unlock" from Galaxy Store or Play Store and follow in-app instructions. This can be faster than the web form.

4
Wait 2-5 business days

Optus sends unlock code via SMS. For prepaid, there is no fee after the 6-month requirement. For postpaid out-of-contract, also free.

Vodafone Unlock (Code: VAU/VA)

1
Check eligibility

Postpaid: handset must be fully paid off. Prepaid: active for 6 months with at least $40 recharge in the last 6 months.

2
Submit unlock request

Vodafone unlock portal: unlock.vodafone.com.au
Or call 1300 650 410

3
Provide IMEI & phone number

You'll need the IMEI and the Vodafone phone number associated with the device (if known).

4
Wait 1-3 business days

Vodafone sends instructions via SMS. Enter the code when prompted with a non-Vodafone SIM inserted.

Other Australian Carriers

Boost Mobile (Telstra MVNO)

Call 1300 662 678 or use unlock request form on their website.

TPG / iiNet / Internode (Vodafone MVNO)

Must have been active for 6+ months. Contact support via online portal.

Felix Mobile (Vodafone MVNO)

Unlock via Felix customer support app or chat.

Woolworths Mobile (Telstra MVNO)

Call 1300 367 979. Must be active 6+ months.

ALDI Mobile (Telstra MVNO)

Contact ALDI Mobile support — typically 12 months active required.

Belong (Telstra MVNO)

Call 1300 235 664. Since Belong uses Telstra network, TEL-locked phones may work.

Samsung-Specific Tips

Alternative unlock code entry

If the SIM lock prompt doesn't appear after inserting a non-carrier SIM:

  1. Settings → Connections → SIM Card Manager
  2. Tap "SIM Lock" or "Network Lock"
  3. Enter the unlock code provided by the carrier
Check lock status via service menu
adb shell service call iphonesubinfo 1 | grep -o '[0-9]\{10,16\}'

Or dial *#7465625# on the Samsung dialer to check network lock status.

Belong + Telstra-locked Samsung

Belong is a Telstra MVNO. TEL-locked phones should accept Belong SIMs since Belong uses Telstra's network infrastructure. If your TEL-locked phone doesn't work with Belong:

  • Check APN: ensure telstra.internet is set
  • Check APN type: default,supl
  • Reset network settings: Settings → General Management → Reset → Reset Network Settings
  • Contact Belong: 1300 235 664
