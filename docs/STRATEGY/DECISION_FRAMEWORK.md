## Assessment Tools

### Founder-Goal Alignment Quiz

**Instructions:** Answer each question honestly. Tally your scores.

**Section 1: Motivation**
1. Why are you starting this business?
   - a) Build wealth (3 pts)
   - b) Solve a problem I care about (2 pts)
   - c) Freedom/flexibility (2 pts)
   - d) Prove something (1 pt)

2. What does success look like?
   - a) $100M+ exit (3 pts)
   - b) $10M+ exit (2 pts)
   - c) $1M-5M/year profit (2 pts)
   - d) Sustainable income (1 pt)

**Section 2: Risk**
3. How much money can you invest?
   - a) $500K+ (3 pts)
   - b) $100-500K (2 pts)
   - c) $50-100K (2 pts)
   - d) <$50K (1 pt)

4. What if it fails?
   - a) Devastating (1 pt)
   - b) Difficult but recoverable (2 pts)
   - c) Acceptable risk (3 pts)

**Section 3: Commitment**
5. How much time can you commit?
   - a) 80+ hours/week (3 pts)
   - b) 50-80 hours/week (2 pts)
   - c) 30-50 hours/week (2 pts)
   - d) <30 hours/week (1 pt)

6. How long will you persist?
   - a) Until it works or money runs out (2 pts)
   - b) 5+ years (3 pts)
   - c) 2-5 years (2 pts)
   - d) 1-2 years (1 pt)

**Scoring:**
- 15-18 pts: VC-scale potential
- 12-14 pts: Angel/Bootstrap hybrid
- 9-11 pts: Bootstrapped
- 6-8 pts: Lifestyle business

## Prioritization Frameworks

### RICE Scoring for Features

**Formula:** RICE = (Reach × Impact × Confidence) / Effort

| Feature | Reach (1-10) | Impact (1-5) | Confidence (1-100%) | Effort (1-10) | RICE Score |
|---------|--------------|--------------|---------------------|---------------|------------|
| | | | | | |
| | | | | | |
| | | | | | |

**Scoring Guide:**
- Reach: How many users affected in given period
- Impact: 0.25 (minimal) to 5 (massive)
- Confidence: 0-100% based on data
- Effort: Person-weeks to complete

**Prioritization:**
1. Sort by RICE score (highest first)
2. Consider dependencies
3. Balance quick wins with strategic bets

### ICE Scoring for Growth Tactics

**Formula:** ICE = Impact × Confidence × Ease

| Tactic | Impact (1-10) | Confidence (1-10) | Ease (1-10) | ICE Score |
|--------|---------------|-------------------|-------------|-----------|
| | | | | |
| | | | | |
| | | | | |

**Scoring Guide:**
- Impact: Potential effect on growth metric
- Confidence: How sure are you it will work?
- Ease: How easy is it to implement?

**Prioritization:**
- ICE >500: Do immediately
- ICE 200-500: Schedule soon
- ICE <200: Backlog or discard

### WSJF for Prioritization

**Formula:** WSJF = (User Benefit + Time Criticality + Risk Reduction) / Job Size

| Initiative | User Benefit (1-10) | Time Criticality (1-10) | Risk Reduction (1-10) | Job Size (1-10) | WSJF |
|------------|---------------------|-------------------------|----------------------|-----------------|------|
| | | | | | |
| | | | | | |
| | | | | | |

**Prioritization:**
- Highest WSJF = highest priority
- Re-evaluate quarterly

### Kano Model for Features

**Categories:**
| Feature | Basic | Performance | Delighter | Don't Care | Reverse |
|---------|-------|-------------|-----------|------------|---------|
| | | | | | |
| | | | | | |
| | | | | | |

**Classification:**
- **Basic:** Must-have, expected (download functionality)
- **Performance:** More is better (speed, quality options)
- **Delighter:** Unexpected, creates wow (AI features)
- **Don't Care:** Users don't care about
- **Reverse:** Some users prefer without

**Prioritization:**
1. All Basic features first
2. High-impact Performance features
3. Select Delighters for differentiation
4. Eliminate Don't Care
5. Consider removing Reverse features

### Ansoff Matrix for Growth

```
                    Existing Products    New Products
Existing Markets    Market Penetration   Product Development
                         (1)                    (2)
                            \                  /
                             \                /
                              \              /
New Markets               Market Development  Diversification
                               (3)                 (4)
```

**Strategies:**
1. **Market Penetration:** Sell more to existing users
   - Tactics: Upsell, cross-sell, increase usage
   
2. **Product Development:** New products to existing users
   - Tactics: AI features, desktop app, mobile app
   
3. **Market Development:** Existing products to new markets
   - Tactics: International, enterprise, new verticals
   
4. **Diversification:** New products to new markets
   - Tactics: Adjacent categories, acquisitions

### Product-Market Fit Framework

**Sean Ellis Test:**
"How would you feel if you could no longer use this product?"
- Very disappointed → PMF indicator
- Somewhat disappointed
- Not disappointed

**PMF Threshold:** 40%+ say "Very disappointed"

**PMF Indicators:**
| Indicator | Not There | Getting Close | PMF Achieved |
|-----------|-----------|---------------|--------------|
| Ellis Score | <40% | 30-40% | 40%+ |
| Retention (D30) | <20% | 20-40% | 40%+ |
| Organic Growth | <10% MoM | 10-20% | 20%+ |
| NPS | <30 | 30-50 | 50+ |
| Word of Mouth | Low | Medium | High |

### Stage Framework

```
STAGE 1: PROBLEM/SOLUTION FIT
- Validate problem exists
- Build solution users want
- Metric: User interviews, beta feedback

STAGE 2: PRODUCT/MARKET FIT
- Users love the product
- Organic growth begins
- Metric: 40%+ Ellis score, retention

STAGE 3: BUSINESS MODEL FIT
- Monetization works
- Unit economics positive
- Metric: LTV:CAC >3:1, payback <6mo

STAGE 4: SCALE
- Growth engine built
- Team scales
- Metric: Consistent MoM growth

STAGE 5: MATURITY
- Market leadership
- Optimization focus
- Metric: Market share, profitability
```
