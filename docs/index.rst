YouTube Enhancement Tools Documentation
=======================================

Welcome to the documentation for YouTube Enhancement Tools, a comprehensive 
toolkit for YouTube content creators with automation, AI tools, and productivity 
enhancements.

Getting Started
---------------

Installation
^^^^^^^^^^^^

To install YouTube Enhancement Tools, simply run:

.. code-block:: bash

    pip install youtube-enhancement-tools

Basic Usage
^^^^^^^^^^^

To use YouTube Enhancement Tools from the command line:

.. code-block:: bash

    youtube-enhancement-tools --url "https://www.youtube.com/watch?v=example"

For batch processing:

.. code-block:: bash

    youtube-enhancement-tools --batch-file urls.txt

Configuration
^^^^^^^^^^^^^

The tool can be configured interactively:

.. code-block:: bash

    youtube-enhancement-tools --setup

Or by creating a ``youtube_tools_config.json`` file with your settings.
